# Student Data Management Using Data Structures

## 📌 Project Overview

The **Student Data Management System** is a C-based project developed using fundamental **Data Structures and Algorithms**. It provides an efficient way to manage student records by allowing users to add, display, search, update, delete, and sort student information.

This project demonstrates the practical implementation of data structures, pointers, structures, linked lists, searching, sorting, and dynamic memory allocation in C.

## ✨ Features

- ➕ Add new student records
- 📋 Display all student records
- 🔍 Search student records
- ✏️ Update student information
- 🗑️ Delete student records
- 🔢 Sort student records
- 💾 Efficient data management
- 🖥️ Menu-driven user interface

## 🛠️ Technologies Used

- **Programming Language:** C
- **Concepts Used:**
  - Structures
  - Arrays
  - Pointers
  - Linked Lists
  - Dynamic Memory Allocation
  - Searching Algorithms
  - Sorting Algorithms
